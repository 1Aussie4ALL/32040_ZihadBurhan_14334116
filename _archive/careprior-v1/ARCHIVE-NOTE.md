# CarePrior v1 — Archived

This directory holds the original CarePrior build: 6 FastAPI microservices, 3 Next.js
frontends, PostgreSQL, and Docker Compose orchestration, along with its supervisor-pitch
deck, 12-week milestone planner, and research/architecture documentation.

It was archived (not deleted) on 2026-08-26 when the project was rebuilt as a single
Next.js + TypeScript + Prisma/SQLite application to match the "AI-Assisted Healthcare
Appointment Request Triage System" Master Build Prompt, which specifies that exact stack
for a solo-student 12-week academic prototype (no Docker/microservices requirement,
mock-AI-first, single deployable app).

Nothing here is deleted — the ideas, rule design, and RBAC/audit thinking from this build
carried forward into the new implementation. See the repo root README.md for the current
build.
